# hns-wallet-bitcoin-kyoto

`hns-wallet-bitcoin-kyoto` provides the Kyoto-only BDK descriptor boundary,
encrypted wallet-state persistence, and native Bitcoin HTLC adapter.

The Bitcoin value permit remains unavailable pending persistence and product
qualification. See the
[workspace repository](https://github.com/handshake-rs/hns-wallet-rs) for the
backend policy and release gates.
