# hns-wallet-ethereum

`hns-wallet-ethereum` provides offline native-ETH derivation plus an immutable
HTLC deployment and evidence-verification policy.

The packaged `contracts/` directory contains the reviewed Solidity source,
deterministic compiler inputs, and generated artifact. Those files do not
authorize a deployment or settlement permit. See the
[workspace repository](https://github.com/handshake-rs/hns-wallet-rs) for the
current release gates.
