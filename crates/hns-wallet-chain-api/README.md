# hns-wallet-chain-api

`hns-wallet-chain-api` defines capability-separated external-chain and atomic
settlement traits for `hns-wallet-rs`.

Traits and permit types are policy boundaries, not evidence that a backend,
settlement adapter, or mainnet path is available. See the
[workspace repository](https://github.com/handshake-rs/hns-wallet-rs) for the
current release gates.
